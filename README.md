One image summing up the world news of Tuesday 24 November 2026.

**Hero:** Asia rallies as AI fears fade — KOSPI +7.5%, Nikkei +4.5%, Taiwan +9.1%,
after Monday's rout; Samsung +9%, SK Hynix +8.8%.

**Inside:** 30 numbered stories, each with its region and source, across Asia,
Europe, the Americas, the Middle East, Africa, markets and the Ukraine war —
plus a stats strip (KOSPI, Nikkei, Taiwan, gold, Bitcoin) and a DATE CHECK box
confirming every story happened or was first reported on 24 November 2026,
by event date.

`main.ts` (Node 22, standard library only) copies `entry.png` (1024×1024,
under 1 MiB) to the output directory. Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
